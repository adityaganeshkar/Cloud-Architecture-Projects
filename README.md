# Cloud Architecture Projects

A portfolio of cloud architecture case studies and practical design exercises across AWS, Azure, and Google Cloud Platform.

> **Featured case study:** [Retail E-commerce for Peak Sales](./01-retail-ecommerce-peak-sales/README.md) — a resilient, event-driven retail platform designed for flash-sale traffic, inventory contention, and payment reliability.

## How to use this repository

Each project contains:
- A business problem and architecture goals
- Architecture diagrams and service responsibilities
- Key design decisions and trade-offs
- Reliability, security, and operational considerations
- A learning guide and practical validation ideas

## Cloud coverage

The case studies map architectural capabilities to AWS, Microsoft Azure, and Google Cloud. The designs are cloud-oriented learning artifacts; they are not claims of deployed production infrastructure.

## Learning approach

Start with the project README, then follow its diagrams, architecture decisions, and learning guide. Try to explain each component's purpose, failure modes, scaling limits, and security boundary before moving on.

## Disclaimer

These materials are educational reference designs. Adapt them to your requirements, threat model, compliance obligations, and provider documentation before using them in a real system.
